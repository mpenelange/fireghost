# Upstream upgrade review — 2026-09-19

Scope: checked repository manifests/lockfiles, official package registries, upstream Git heads, release notes, and public OCI manifests. These are upgrade candidates, not tested replacement builds. No dependency, pin, deployment, or production state was changed. Version numbers below describe this checkout, not necessarily the deployed Hermes binary.

## Recommended order

1. Address the PDF dependency findings in the companion security audit and rebuild the router with a supported Go release.
2. Trial `htmd` 0.5.5 and the Camofox fork's reliability changes in isolated builds; these have the clearest direct retrieval benefits.
3. Trial browser image updates individually against the browser regression matrix, then review larger parser/runtime API migrations.
4. Keep each behavioral upgrade separate from source-history import work. Preserve immutable baseline pins and require equivalence/regression approval before touching Hermes production.

## Toolchain and container maintenance

- **Router Go `1.24.6` → `1.26.8` or `1.27.1`**: official live download API lists these two supported lines. `router/go.mod` has no third-party modules; the toolchain is its principal dependency. Prefer a supported patched builder and validate normal tests, race tests and vet in Docker, per router instructions. Update CI/test images consistently and verify a new immutable builder digest. Go's policy supports a release until two newer major releases exist. [Live release API](https://go.dev/dl/?mode=json), [support policy](https://go.dev/doc/devel/release#policy).
- **Alpine `3.22.1` → `3.22.6`** is the smaller runtime refresh; `3.24.2` is also available. Keep the current branch for the first change if minimizing OS drift. Verify CA roots, wget healthcheck and non-root storage permissions. Release availability does not prove the installed image's APK inventory or CVE status. [Official release data](https://alpinelinux.org/releases.json).
- CRW uses mutable `rust:1.93-bookworm` and `debian:bookworm-slim`; record exact rebuilt digests. The Rust stable channel dated 2026-09-03 reports `1.98.1` (`48a229cea`, 2026-09-01), versus builder `1.93`; evaluate compiler/MSRV changes in a separate build-only update. A Debian major-version migration is not needed to test application upgrades; first refresh/pin the existing supported base and inspect its package inventory. [Rust stable manifest](https://static.rust-lang.org/dist/channel-rust-stable.toml).
- `marked` is declared `^18.0.0` for documentation generation; npm currently reports `18.0.13`. There is no npm lockfile in the inspected checkout, so an **installed** version cannot be established. Fresh installs may already resolve `18.0.13`. Lock it for reproducible docs builds. [npm metadata](https://registry.npmjs.org/marked/latest).
