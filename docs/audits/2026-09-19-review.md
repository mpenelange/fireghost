## Recommended order of work

1. **Close CRW's internal-network request paths.** Caller-controlled LLM URLs bypass page URL safety, browser navigation/subrequests lack destination enforcement, and HTTP DNS validation is detached from connection establishment. Prioritize endpoint allowlisting and actual transport/egress enforcement, preserving explicitly trusted operator-configured LLM services. Root Compose authentication and IP allowlisting reduce caller access but do not protect a legitimate scrape of malicious public content.
2. **Patch reachable parser/transport dependencies and rebuild on supported Go.** The PDF path uses vulnerable `lopdf 0.41.0`; the matching stack-overflow advisory can abort a process despite `catch_unwind`. Coordinate `pdf-inspector` and `lopdf` upgrades so the vulnerable transitive copy disappears. Follow the dependency report for TLS/HTTP and other matches. Advisory matches alone do not establish exploitability.
3. **Make response and request limits constrain allocation.** CRW reads upstream bodies completely before checking their actual size. The router buffers requests before its flight limit, permits unbounded waiting callers, and bypasses that limit for invalid JSON. Stream with byte caps and add bounded admission before allocation; test with isolated fixtures.
4. **Correct cloud credit accounting before relying on hard spending limits.** Fixed per-call reservations undercount requests with additional results or premium options. Reserve a conservative request-dependent maximum and restrict options whose charge cannot be bounded. Cloud fallback is disabled by default.
5. **Stage functional upgrades independently.** Review CRW upstream changes/backports and newer Camofox/Lightpanda candidates, followed by targeted extraction/HTTP-library upgrades. Preserve baseline evidence, component boundaries, immutable candidate pins, and regression approval before any production rollout.
6. **Follow up on narrower issues.** Protect CRW's direct administrative route; unify configured BYOK policy enforcement; eliminate full-cache scans on insertion; secure backup permissions; pin CI actions by commit. See detailed reports for prerequisites and severity.
