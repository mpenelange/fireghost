A readable article fixture

This article explains how a bounded browser extraction keeps useful prose and the links its author supplied. The fixture deliberately contains complete sentences, punctuation, and a substantial paragraph so that the real readability algorithm has article content to distinguish from navigation. The original document must remain available for subsequent harvesting passes, which is why the algorithm receives a detached clone.

A second paragraph provides the additional context that readers need. A relative source guide must remain a useful absolute link, and an external reference must retain its destination. Formatting such as important prose, emphasis, and literal code is part of the article rather than page chrome.

The result is a compact representation of the selected article. It does not contain a serialized copy of the complete page, scripts, advertising widgets, or forms. The test checks the actual Mozilla algorithm and the returned HTML rather than recreating the extraction rules in a separate test implementation.
